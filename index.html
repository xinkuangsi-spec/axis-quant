(02) // 五大历史纪元

量化交易发展脉络：半个世纪的宽客征途

五大关键时代，梳理从学术象牙塔的随机漫步理论到华尔街超算中心与人工智能的跨越

1970 — 1985 · 理论奠基

期权定价与现代金融工程萌芽

在 70 年代前，华尔街全凭直觉和看图做盘。1973 年 Fischer Black、Myron Scholes 和 Robert Merton 提出 B-S 期权定价模型，给衍生品敲定了客观数学定价法。同期的 Ed Thorp（数学家，21点算牌之父）创立了首家电脑量化对冲基金 Princeton Newport Partners，首次用计算机寻找可转债套利机会。

  • B-S 期权定价公式诞生
  • 可转债折价套利理论
  • 首批宽客进入对冲基金界
1985 — 2000 · 宽客崛起

大奖章基金与统计套利的黄金时代

冷战密码学家 Jim Simons 创立 Renaissance Technologies（文艺复兴科技），招募天体物理学家与数学家，摒弃任何基本面直觉，完全依靠纯数据驱动与隐马尔可夫模型捕捉市场非理性微动。大奖章基金创下连续 30 年费前年化收益超 66% 的神话。然而 1998 年 LTCM（长期资本管理）因黑天鹅流动性枯竭轰然倒闭，给行业敲响了风险控制的警钟。

  • 隐马尔可夫与统计套利模型
  • 文艺复兴科技大奖章基金传奇
  • LTCM 危机与风险敞口深刻教训
2000 — 2015 · 电子革命

微波网络、暗池与超高频交易 (HFT)

随着交易所全面电子化，速度从“秒”被压缩到“纳秒”。对冲基金为了比对手快几个微秒，斥资数亿美元铺设芝加哥到纽约的激光微波直连塔，使用 FPGA 硬件重写网卡逻辑。Citadel、Virtu Financial、Jump Trading 成为新时代的市场流动性提供者，同时也诱发了 2010 年惊心动魄的“美股闪崩”（Flash Crash）。

  • 订单簿微观结构与纳秒撮合
  • FPGA 硬件加速与微波通信网络
  • 流动性做市 (Market Making) 与暗池
2015 — 2022 · 因子工场

多因子模型与另类数据爆发

量化机构从比拼速度走向比拼信息维度。以 Fama-French 五因子（市值、账面市值比、盈利能力、投资模式、动量）为基础的多因子选股成为主流框架；WorldQuant 建立起拥有成千上万个Alpha因子的因子库。与此同时，卫星图（监控零售商停车场汽车数量）、信用卡脱敏消费流水、供应链物流数据等另类数据被大规模引入策略。

  • 多因子正交化与风险模型 (Barra)
  • 卫星与信用卡另类数据挖掘
  • 加密货币全天候量化套利兴起
2023 — 至今 · 智能体前沿

大语言模型与多智能体自主决策

生成式人工智能与大语言模型突破了非结构化文本的壁垒。如今的量化系统不仅使用深度强化学习（RL）优化执行滑点，更通过多个专家智能体（Agent）协同工作：一个智能体实时解析全球央行纪要与供应链新闻，另一个智能体动态构建策略因子，第三个智能体执行风控压力测试。人类宽客正转变为智能体系统的架构师与裁判员。

  • LLM 财报与非结构化文本情感量化
  • 强化学习连续动作执行与滑点控制

(03) // 算法实战教学

零基础量化实战：双均线突破与回测模拟器

理解量化交易最经典、最直观的趋势跟踪策略——双均线（Dual SMA Cross）。在下方实时调节参数，观察策略在真实波动数据下的表现。

1. 策略数学逻辑

设定一条快速移动平均线（SMA Fast）与一条慢速移动平均线（SMA Slow）。当快线自下而上穿过慢线时，形成「黄金交叉（Golden Cross）」，发出做多信号；当快线自上而下跌破慢线时，形成「死亡交叉（Death Cross）」，平仓或发出做空信号。

2. 关键评估指标定义

• 夏普比率 (Sharpe Ratio): (策略年化收益率 - 无风险利率) / 策略收益率年化波动率。衡量承担每单位风险所获取的超额回报，>1.5 为优秀，>2.5 为顶级宽客水准。 • 最大回撤 (MDD): 资产净值曲线从峰值跌落至谷底的最大跌幅百分比，是衡量爆仓风险的核心红线。

3. 交互式回测控制台

拖动右侧滑块修改均线周期与止损阈值，回测引擎会在浏览器端即时重算所有买卖点与资产收益曲线！

工业级 Python 策略代码范例 (Backtrader & Pandas) 
import backtrader as bt
import pandas as pd
import numpy as np

class DualSMACrossoverStrategy(bt.Strategy):
    """
    工业级双均线交叉趋势动量策略
    包含动态止损、滑点规避与资产头寸自适应控制
    """
    params = (
        ('fast_period', 8),
        ('slow_period', 24),
        ('stop_loss_pct', 0.05),
    )

    def __init__(self):
        # 1. 初始化快速与慢速移动平均线指标
        self.fast_sma = bt.indicators.SimpleMovingAverage(
            self.data.close, period=self.params.fast_period
        )
        self.slow_sma = bt.indicators.SimpleMovingAverage(
            self.data.close, period=self.params.slow_period
        )
        # 2. 构造交叉信号指示器: 1 为金叉买入, -1 为死叉卖出
        self.crossover = bt.indicators.CrossOver(self.fast_sma, self.slow_sma)
        self.order = None
        self.entry_price = None

    def next(self):
        if self.order:
            return  # 避免挂单竞争

        # 硬止损逻辑检查
        if self.position and self.entry_price:
            current_loss = (self.entry_price - self.data.close[0]) / self.entry_price
            if current_loss >= self.params.stop_loss_pct:
                self.log(f'触发止损平仓: 现价 {self.data.close[0]:.2f}, 亏损 {current_loss*100:.2f}%')
                self.order = self.close()
                return

        # 金叉买入入场
        if not self.position:
            if self.crossover > 0:
                self.log(f'黄金交叉产生: 买入现价 {self.data.close[0]:.2f}')
                self.entry_price = self.data.close[0]
                self.order = self.buy()
        # 死叉卖出离场
        elif self.crossover < 0:
            self.log(f'死亡交叉产生: 卖出平仓 {self.data.close[0]:.2f}')
            self.order = self.close()

    def log(self, txt):
        dt = self.datas[0].datetime.date(0)
        print(f'[{dt.isoformat()}] {txt}')

+

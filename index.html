从 1970 年代随机漫步假说与布莱克-斯科尔斯公式，到大奖章基金的统计套利，再到今日大语言模型与多智能体自适应挖掘——量化交易如何用数学语言，将市场的不确定性重构为概率优势。

第一章 · 1973

期权定价与连续时间金融工程的诞生

在 1970 年代之前，金融市场被视为不可预测的随机游走，投资机构几乎完全依靠基本面定性判断与图表技术分析。1973 年，费希尔·布莱克（Fischer Black）与迈隆·斯科尔斯（Myron Scholes）发表了划时代的期权定价公式，随后罗伯特·默顿（Robert Merton）进一步将其扩展为严谨的连续时间金融数学大厦。

B-S 模型将复杂的衍生品定价问题，精妙地转化为物理学中的一维热传导扩散方程。通过在标的资产与无风险债券之间构建动态对冲组合，消除无系统风险，为现代全球衍生品市场的繁荣奠定了基石。

模型现实边界

B-S 模型假设标的资产回报服从对数正态分布且波动率为常数。但在真实市场中，极度恐慌时往往出现“肥尾效应”与“波动率微笑”（Volatility Smile），促使后来的宽客开发出局部波动率与随机波动率模型（如 Heston 模型）。

第二章 · 1988

大奖章基金的神话与统计套利革命

冷战时期的密码破译专家吉姆·西蒙斯（Jim Simons）在长岛创立文艺复兴科技公司。与华尔街传统商学院毕业生不同，西蒙斯几乎只招募理论物理学家、天体物理学家与纯数学家，彻底摒弃主观直觉判断，完全用海量历史行情数据驱动决策。

由詹姆斯·埃克斯（James Ax）等人开发的大奖章基金（Medallion Fund）首创了统计套利（Statistical Arbitrage）与配对交易（Pairs Trading）：当具有长期协整关系的两个资产价差偏离历史均值超过 2 个标准差时，买入相对低估资产、做空相对高估资产，并在价差回归均值时获利平仓。

1998 LTCM 危机启示录

由诺贝尔奖得主默顿和斯科尔斯坐镇的长期资本管理公司（LTCM），因过度杠杆（资产负债比高达 25:1）并在俄罗斯主权债务违约时遭遇全球流动性骤枯竭，在数月内亏损超 40 亿美元濒临清盘，警示量化界：流动性风险是数学模型最大的盲区。

第三章 · 2000 — 2015

算法交易、超低延迟与 2010 闪崩之谜

随着全球主要证券交易所全面转向电子化撮合，量化机构从“日级别模型”向“微秒甚至纳秒级别”突进。Citadel、Virtu Financial 和 Jump Trading 斥巨资架设连接芝加哥商品交易所与纽约证券交易所的微波直线塔，并使用 FPGA 硬件重写底层网卡逻辑。

2010 年 5 月 6 日，著名的“美股闪崩”（Flash Crash）爆发：道琼斯指数在数分钟内狂泻近 1,000 点，随后又迅速反弹。事件揭示了现代高频做市商在市场遭遇单边大单冲击时会瞬间撤单自保，导致全市场流动性在毫秒内归零的微观结构脆弱性。

第四章 · 2015 — 2022

多因子投资、风险模型与另类数据纪元

速度的军备竞赛边际收益递减后，宽客将重心转向信息维度。尤金·法玛（Eugene Fama）与肯尼斯·弗伦奇（Kenneth French）的多因子资产定价模型成为公募量化与 Smart Beta 的底层基石；AQR、Two Sigma 与 WorldQuant 建立了涵盖动量、价值、质量、低波动与规模的因子工场。

与此同时，卫星遥感图像（监测大型零售商停车场车流量与原油储罐浮顶高度）、匿名信用卡脱敏流水、供应链运单等“另类数据”（Alternative Data）被引入多因子策略，使得量化机构能够领先季度财报预测公司基本面拐点。

第五章 · 2023 — 至今

大语言模型、深度强化学习与智能体阿尔法

随着生成式人工智能突破非结构化文本的理解边界，量化系统开始全面部署多智能体协作网络：专门的智能体负责实时解析全球央行纪要与供应链突发新闻，推断宏观体制转换；强化学习（RL）算法在订单执行端动态学习最优拆单策略以最小化市场冲击滑点。

未来的量化竞争不再是单一公式的保密，而是算法自我进化、数据流水线工程化与风险极端压力测试体系的综合协同能力。

import backtrader as bt
import pandas as pd
import numpy as np

class DualSMACrossoverStrategy(bt.Strategy):
    """
    工业级双均线动量突破与硬止损策略
    支持多资产回测、滑点规避与仓位自适应控制
    """
    params = (
        ('fast_period', 10),
        ('slow_period', 30),
        ('stop_loss_pct', 0.05),
    )

    def __init__(self):
        self.fast_sma = bt.indicators.SimpleMovingAverage(
            self.data.close, period=self.params.fast_period
        )
        self.slow_sma = bt.indicators.SimpleMovingAverage(
            self.data.close, period=self.params.slow_period
        )
        self.crossover = bt.indicators.CrossOver(self.fast_sma, self.slow_sma)
        self.order = None
        self.entry_price = None

    def next(self):
        if self.order:
            return  # 避免未成交挂单竞争

        # 硬止损检查
        if self.position and self.entry_price:
            drawdown = (self.entry_price - self.data.close[0]) / self.entry_price
            if drawdown >= self.params.stop_loss_pct:
                self.order = self.close()
                return

        # 黄金交叉买入
        if not self.position and self.crossover > 0:
            self.entry_price = self.data.close[0]
            self.order = self.buy()
        # 死亡交叉卖出
        elif self.position and self.crossover < 0:
            self.order = self.close()
